# SD signature assets

Small transparent PNG icons for personal email signatures (Luminous Identity — SD Edition).
Icons only: no names, contact details or signature HTML are stored here.

Public URL pattern (jsDelivr, pinned to release tag v1):

    https://cdn.jsdelivr.net/gh/sandeepu76/sd-signature-assets@v1/icons/v1/<name>.png

| File | Used for | Shown at |
| --- | --- | --- |
| phone.png | before phone numbers | 13–14 px |
| mail.png | before email address | 13–14 px |
| location.png | before city | 13–14 px |
| linkedin-brand / -navy / -white.png | LinkedIn link | 17–18 px |
| whatsapp-brand / -navy / -white.png | WhatsApp links | 17–18 px |

Rendered at 64 × 64 px for sharp display on high-density screens.
Never replace a file in place: publish changes as icons/v2 under a new tag so existing signatures keep working.
